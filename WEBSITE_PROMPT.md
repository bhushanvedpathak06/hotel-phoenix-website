# Website creation prompt — Hotel Phoenix International

Act as a senior product designer and frontend engineer with 20 years of experience creating premium, conversion-focused hospitality websites.

Create a complete, responsive, production-minded hotel website for **Hotel Phoenix International**, located at **1st Floor, Shanawaz Building, Kale Marg, near Jain Paper Box Company, Kamani, Kurla West, Mumbai, Maharashtra 400070, India**.

## Design direction
Create an elegant, modern hospitality experience with a warm editorial visual identity: deep forest green, warm ivory, muted brass/gold accents, generous whitespace, refined serif display typography paired with a clean sans-serif, subtle transitions, and a high-quality responsive layout. The result should feel polished, trustworthy, distinctive, and easy to use—not like a generic hotel template.

## Required sections and functionality
- Sticky responsive navigation with mobile menu.
- Hero section with a clear value proposition and primary booking/enquiry CTA.
- Property introduction.
- Responsive photo gallery with lightbox.
- Amenities grid.
- Guest rating/review summary linking to the public Google listing.
- Location/address section with directions link.
- Booking enquiry form with name, phone, check-in, check-out, guest count, and optional message.
- Footer with useful navigation.
- Accessible labels, keyboard-friendly controls, responsive typography, and sensible hover/focus states.
- SEO title, description, and mobile viewport metadata.

## Technology
Use React with Vite and JavaScript for the initial implementation so a beginner can run and maintain it. Use clean reusable components and Lucide icons. Keep styling maintainable and responsive. TypeScript may be introduced later when the project grows.

## Accuracy and trust requirements
Use only verified property facts. The public Google hotel listing currently reports 3.6/5 from 419 reviews and a 2:00 PM check-in; re-verify before launch. Do not invent room names, prices, phone numbers, testimonials, policies, or amenities. Mark any unconfirmed details clearly. Use clearly identified illustrative images during development and replace them with hotel-approved photographs before publishing. The enquiry form must not claim to send or store data unless a real verified contact destination/backend is configured.

## Delivery
Provide the complete source project, package scripts, README setup instructions, and a launch-readiness checklist. The project must run with `npm install` and `npm run dev`.
